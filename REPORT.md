## Виконання роботи

### Завдання 1. Перевірка даних

1. Створили файл [`validation.py`](validation.py) з трьома функціями: `check_positive_assert` (через `assert`),
   `check_positive` (через `raise ValueError`) та `create_name`.
2. Програма вивела такі результати для правильного й неправильного вводу:

| Ввід | Результат |
|------|-----------|
| `"5"` (правильний) | повертає `5.0` |
| `"-3"` (неправильний) | `ValueError: Число має бути більшим за нуль` |
| `"abc"` (неправильний) | `ValueError: Введіть число, а не текст` |
| `-1` для `assert` | `AssertionError: Число має бути більшим за нуль!` |

3. Навчились відрізняти `assert` (внутрішня перевірка, що зупиняє програму) від `raise ValueError`
   (повідомлення про неправильний аргумент).

### Завдання 2. Тестування функцій

1. Створили [`text_utils.py`](text_utils.py): `count_symbols`, `divide`, `count_vowels`
   (рахує голосні українського й англійського алфавітів, регістр не важливий).
2. Написали тести (клас `TestTextUtils` у [`test.py`](test.py)):
   * звичайний рядок `"hello"` → 2;
   * рядок без голосних `"bcd"` → 0;
   * великі літери `"AEI"` → 3;
   * порожній рядок → 0;
   * рядок із цифрами `"12345"` → 0;
   * українські літери: `"Привіт"` → 2, `"Україна"` → 4;
   * `divide(1, 0)` дає `ZeroDivisionError`.

### Завдання 3. Приклад із класом Figure

1. Створили [`app.py`](app.py): клас `Figure(figure_type, length)` з властивостями `get_figure_type`,
   `get_figure_length` та методом `get_angles`.
2. Ручна перевірка (`python app.py`):

```
квадрат 4 [90, 90, 90, 90]
прямокутник 6 [90, 90, 90, 90]
трикутник 3 [60, 60, 60]
```

3. Додали тести: кути для квадрата, прямокутника й трикутника; нульова довжина, від'ємна довжина
   та невідомий тип фігури (`ValueError`).

**Тест, який спочатку не проходив.** У `get_figure_length` було внесено помилку `return self._length - 1`.
Результат запуску до виправлення:

```
FAIL: test_length
AssertionError: 4 != 3
FAIL: test_figure_lengths (length=1)
AssertionError: 1 != 0
FAIL: test_figure_lengths (length=5)
AssertionError: 5 != 4
```

Після виправлення на `return self._length` усі тести `TestFigure` проходять (8 із 8, `OK`).

### Завдання 4. Життєвий цикл, subTest і mock

1. `setUp` створює новий `Figure("квадрат", 4)` перед кожним тестом, тому тести незалежні.
2. **subTest** (`test_figure_lengths`, `test_all_types_subtest`) перевіряє кілька наборів даних в одному тесті.
   Якщо один набір не проходить, видно, який саме (`length=5`), а решта наборів усе одно виконуються.
   Це добре видно у виводі помилки вище: окремо показано `length=1`, `length=5`, `length=10`.
3. **mock** ([`input_app.py`](input_app.py)). Функція `ask_number()` викликає `input()`.
   Через `@patch("builtins.input", return_value="5")` ввід підміняється, тест не чекає на клавіатуру,
   а `assert_called_once()` перевіряє, що `input` викликали один раз.
